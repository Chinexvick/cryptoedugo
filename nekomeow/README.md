# NekoMeow Website

NekoMeow's official project information and awareness website.

## Technology Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Local Development

Install dependencies:

npm ci

Start the development server:

npm run dev

The development server runs at http://localhost:3000.

## Production

Build the application:

npm run build

Start the production server:

npm run start

## Project Structure

app/page.tsx - Website content, project information and links
app/layout.tsx - Layout and metadata
app/globals.css - Global styles
public/images - Website assets

## Contract Address

The contract address and related links are configured in
app/page.tsx.

Verify any replacement contract address independently before
publishing changes.

## Deployment and Maintenance

The receiving developer is responsible for deployment,
hosting configuration, domain connection, future updates
and ongoing maintenance.

This repository contains the informational website only.
It does not include the separate NekoMeow utility platform.
